# Security Policy

This repository contains the public Xenith status page. It holds no application
secrets or user data — the monitoring checks only request public health
endpoints.

## Reporting a vulnerability

If you discover a security issue in Xenith — whether in this page or the main
product — **please do not open a public issue**. Instead, report it privately:

- Email **security@xenith.life**, or
- See the responsible disclosure details at
  [xenith.life/security](https://xenith.life/security).

We appreciate responsible disclosure and will respond as quickly as we can.
